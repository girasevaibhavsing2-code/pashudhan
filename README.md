# 🐄 पशुधन बाजार (Pashudhan Bazar)
> **महाराष्ट्रातील शेतकऱ्यांसाठी जनावरांची मोफत व थेट खरेदी-विक्री वेब प्लॅटफॉर्म**

---

## 📌 प्रकल्प परिचय (Project Overview)
**पशुधन बाजार** ही एक आधुनिक आणि शेतकरी-स्नेही (Farmer-Friendly) वेब अ‍ॅप्लिकेशन प्रणाली आहे. याच्या माध्यमातून ग्रामीण भागातील शेतकरी कोणत्याही मध्यस्थाशिवाय (दलालांशिवाय) गाय, म्हैस, बैल, शेळी-मेंढी यांसारख्या जनावरांची खरेदी आणि विक्री थेट करू शकतात. 

या प्रणालीमध्ये महाराष्ट्रातील सर्व **३६ जिल्हे** आणि **३५८ अधिकृत तालुके** समाविष्ट असून, शेतकऱ्यांना आपल्या गावात बसून जनावरांची जाहिरात प्रकाशित करणे व ग्राहक शोधणे सहज शक्य होते.

---

## ✨ मुख्य वैशिष्ट्ये (Key Features)

- **📍 जिल्हा व तालुका कॅस्केडिंग (Dynamic Filtering):**  
  जिल्हा निवडल्यानंतर त्या जिल्ह्यांतर्गत येणारे सर्व अधिकृत तालुके लोड होतात. तसेच शेतकरी आपल्या गावाचे किंवा वाडी-वस्तीचे नाव सहज नोंदवू शकतात.

- **🐂 स्मार्ट फॉर्म लॉजिक (Dynamic Form Fields):**  
  नोंदणी करताना 'बैल' निवडल्यास दुधाची क्षमता आणि वेताशी संबंधित रकाने (Lactation & Milk capacity) आपोआप लपवले जातात.

- **📸 गॅलरी व कॅमेरा सपोर्ट (Image Upload & Preview):**  
  शेतकरी मोबाईल गॅलरी किंवा कॅमेऱ्यातून जनावरांचा प्रत्यक्ष फोटो अपलोड करू शकतात आणि त्याचा लाईव्ह प्रिव्ह्यू पाहू शकतात.

- **🤝 थेट संवाद (Direct Call & WhatsApp):**  
  खरेदीदार एका क्लिकवर शेतकऱ्याला थेट फोन करू शकतात किंवा पूर्वरचित मराठी संदेशासह व्हॉट्सअ‍ॅपवर चॅट करू शकतात.

- **🏷️ जाहिरात नियंत्रण (Mark as Sold & Delete):**  
  जनावर विकले गेल्यानंतर त्यावर **'विकले गेले (SOLD)'** असा शिक्का मारून कॉल बटणे लॉक करता येतात किंवा जाहिरात कायमस्वरूपी हटवता (Delete) येते.

- **💾 डेटा सेव्हिंग (Local Storage Persistence):**  
  नोंदवलेला डेटा ब्राउझरच्या लोकल स्टोरेजमध्ये सुरक्षित राहतो.

## 🛠️ वापरलेले तंत्रज्ञान (Tech Stack)

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **डिझाइन व लेआउट:** CSS Flexbox & CSS Grid, Custom Modern UI
- **फॉन्ट:** [Google Font - Yantramanav](https://fonts.google.com/specimen/Yantramanav) (मराठी देवनागरीसाठी)
- **आयकॉन्स:** [Font Awesome 6](https://fontawesome.com/)
- **डेटा साठवणूक:** Browser LocalStorage API
